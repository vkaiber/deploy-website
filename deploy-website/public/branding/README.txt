DEPLOY WEBSITE BRAND ASSETS

Replace these files with your own assets without changing the application code:
- /public/branding/logo.png    -> main website logo
- /public/branding/account.png -> account/profile icon
- /public/favicon.png         -> browser favicon

Recommended sizes:
- logo.png: 1024x1024 PNG for an icon, or 1600x500 for a wordmark.
- account.png: 512x512 PNG, preferably transparent.
- favicon.png: 512x512 PNG, simple icon preferred.

Never commit private credentials, .env files, database dumps, user data, or Cloudflare credential files.
